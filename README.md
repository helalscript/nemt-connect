A smart, RFID-powered customer and package management system. Designed for businesses that manage clients and deliver services using RFID-based activation — like rental services, gyms, or access control platforms.

---

## 🚀 Features

### 🧑‍💼 User Panel
- Add and manage your own customers.
- Assign specific packages to customers.
- Activate/deactivate packages via RFID scan.

### 🛠️ Admin Panel
- View all users and their customer data.
- Monitor package activity and scan logs.
- Full control over service management.

### 📡 RFID Integration
- RFID chips are linked to customer packages.
- Scanning triggers API to automatically activate/deactivate services.
- Seamless, touchless automation.

---

## 🧠 Use Cases
- Smart shoe/juta rental systems
- memberships
- RFID-based subscription services
- Access control (e.g. events, co-working spaces)
